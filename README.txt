============================================================
              SNAPROUTE - SCREEN CROP OCR & IMAGE SEARCH
============================================================

A beautiful, ultra-fast screen cropping, text recognition (OCR), and smart visual routing utility. 

No setup, no dependencies, no configuration required!

------------------------------------------------------------
🚀 QUICK START
------------------------------------------------------------
1. Double-click "SnapRoute.exe" to launch it.
2. The application will hover silently in the background. 
   (You will see a neon-green target icon in your System Tray).

------------------------------------------------------------
🎯 HOW TO USE IT
------------------------------------------------------------
1. Press "Ctrl + Shift + S" anywhere on your screen.
2. Click and drag your mouse to draw a box over any region.
3. Release the mouse. An elegant glassmorphic menu will fade in.
4. Click:
   - "Copy Text"   : Copies the recognized text to your clipboard (shown if text is found).
   - "Copy Image"  : Copies the cropped image data to your clipboard (shown if no text is found).
   - "Search Text" : Opens a Google Search tab for the extracted text (active if text is found).
   - "Search Image": Uploads the crop securely to Uguu.se and performs a Google Lens visual search.

------------------------------------------------------------
💡 SHORTCUTS & CONTROLS
------------------------------------------------------------
- Trigger Selection : Ctrl + Shift + S
- Cancel Selection  : Escape key
- Exit Utility      : Right-click the neon green target icon in your 
                      System Tray (bottom right) and select "Quit".
